# 历史星链探索 - MVP 设计规格书

**日期**: 2026-05-24  
**版本**: v1.0 (MVP)  
**状态**: 设计中

---

## 1. 概念与愿景

一款赛博朋克风格的历史探索游戏。用户通过交互式柱状图俯瞰中外历史长河，点击任意历史节点即可进入"星链视图"——以该事件为中心，展开因果关系网络，每个关联事件按重要性分级，引导用户穿梭于历史的关键节点之间。

**核心体验**: 探索欲驱动，像星际导航一样在历史中跳跃，每次点击都是一次发现。

---

## 2. 设计语言

### 美学方向
赛博朋克 + 历史厚重感：暗色调背景、霓虹光晕、数据流线条，暗示"用未来科技解读过去"。

### 色彩系统
```
背景主色:     #0a0a0f (深空黑)
次级背景:     #12121a (暗紫黑)
卡片背景:     #1a1a2e (深靛蓝)
霓虹主色:     #00f5ff (青色/赛博青)
霓虹强调:     #ff00ff (品红)
警示/重要:   #ff3366 (红粉)
金色/历史:    #ffd700 (琥珀金)
成功/完成:   #00ff88 (翠绿)
文字主色:     #e0e0e0 (浅灰白)
文字次级:     #888888 (灰色)
边框线:       rgba(0, 245, 255, 0.3) (半透明青)
```

### 字体
- 标题: Orbitron (科技感) / Noto Serif SC (历史内容)
- 正文: Noto Sans SC
- 等宽/数据: JetBrains Mono

### 空间系统
- 基础单位: 8px
- 内边距: 16px / 24px / 32px
- 卡片圆角: 8px
- 霓虹发光: box-shadow: 0 0 20px rgba(0, 245, 255, 0.5)

### 动效哲学
- 霓虹闪烁: 微妙的脉动光晕，营造"活着的系统"感
- 过渡: 300ms ease-out，流畅但不拖沓
- 星链展开: 从中心向外辐射的动画，暗示因果扩散
- 悬停: 发光增强 + 轻微缩放，暗示可交互

├─────────────────────────────────────────────────────────────┤
│                                                             │
│   ┌─────┐                                                   │
│   │     │  ┌─────┐                                         │
│   │     │  │     │        ┌─────┐                           │
│   │     │  │     │        │     │  ┌─────┐                 │
│   │     │  │     │        │     │  │     │                 │
│   │     │  │     │        │     │  │     │                 │
│   └─────┘  └─────┘        └─────┘  └─────┘                 │

- 横轴：公元前/公元后时间线

- 悬停显示事件名称气泡

### 星链视图 - 事件详情
```
┌─────────────────────────────────────────────────────────────┐
│  ← 返回柱状图                              [事件名称]       │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│           [影响事件2]                                       │
│               ↓                                             │
│   [影响事件1] ← [中心事件] → [结果事件1]                    │
│               ↓                   ↓                          │
│           [影响事件3]         [结果事件2]                    │
│                                                             │
│  ┌─────────────────────────────────────────────────────┐   │
│  │ 事件描述: ...                                       │   │
│  │ 影响原因: · 原因1                                   │   │
│  │          · 原因2                                   │   │
│  │ 历史意义: ...                                       │   │
│  └─────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────┘
```

- 中心事件发光显示
- 关联事件按因果关系分布（前因在上/左，结果在下/右）
- 连线表示因果关系，粗细表示影响强度
- 点击关联事件可继续深入探索

## 4. 功能与交互

### 核心功能

#### 4.1 柱状图浏览
- 显示历史事件分布
- 中国/外国/全部筛选
- 时间范围缩放（可选）
- 悬停显示事件简要信息

#### 4.2 事件点击 → 星链视图
- 点击柱形进入详情
- 展开前因（最多5个）和结果（最多5个）
- 关联事件按重要性排序
- 重要性分3级：核心(大圆)、重要(中圆)、一般(小圆)

#### 4.3 星链导航
- 点击关联事件继续探索
- 面包屑记录探索路径
- 返回按钮回到柱状图
- 探索历史记录（本次会话）

### 交互细节

| 交互 | 行为 |
|------|------|
| 悬停柱形 | 发光增强 + 显示事件名气泡 + 放大1.05x |
| 点击柱形 | 切换到星链视图，300ms过渡动画 |
| 悬停关联节点 | 高亮路径连线 + 显示事件简介 |
| 点击关联节点 | 以该节点为中心重新渲染星链 |
| 返回按钮 | 回到柱状图或上一级星链 |
| 筛选切换 | 柱状图重新渲染，淡入淡出 |

### 边界情况
- 无关联事件：显示"暂无因果数据"提示
- 数据加载中：骨架屏 + 脉动动画
- 移动端适配：柱状图可横滑，星链视图垂直滚动

## 6. 技术方案

### 技术栈
- **纯前端**: HTML5 + CSS3 + Vanilla JavaScript
- **图表**: 原生Canvas/SVG实现柱状图
- **动效**: CSS Transitions + requestAnimationFrame
- **数据**: 内联JSON（后续替换为API）

### 文件结构
```
hitstorygame/
├── index.html          # 主页面
├── styles/
│   └── main.css        # 所有样式
├── scripts/
│   ├── app.js          # 主入口
│   ├── data.js         # 静态数据
│   ├── chart.js        # 柱状图模块
│   └── starlink.js     # 星链视图模块
├── assets/
│   └── (可选图标)
└── docs/
    └── specs/
        └── 2026-05-24-history-starlink-design.md
```

### 关键实现
1. **柱状图**: Canvas绑定点击事件，根据坐标计算点击的事件
2. **星链**: 力导向图布局，以中心事件为锚点展开
3. **状态管理**: 简单的全局state对象记录当前视图和探索历史
4. **路由**: 基于hash的简单路由 (#/event/qin_unification)
